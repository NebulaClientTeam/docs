## Requirements

| Requirement | Version |
| --- | --- |
| Minecraft | 26.2 |
| Mod loader | Fabric 0.19.5+ |
| Java | 25+ |

## Before You Start

Make sure you've purchased Premium from the [official website](https://nebulaclient.net/pricing). The free **Basic** plan has been discontinued.

<Warning>
    **[nebulaclient.net](https://nebulaclient.net/) is the only official website.** Nebula is not distributed anywhere else.

    Any site, video, or Discord server offering a "free", "cracked", or "leaked" build of Nebula is distributing malware. These builds are RATs that steal your Minecraft account, Discord token,
    browser passwords, and crypto wallets. There is no working free version.

    If you are unsure whether a download is legitimate, ask in the [official Discord](https://nebulaclient.net/discord) before running it.
</Warning>

## Installing Nebula

<Steps>
    <Step title="Download Nebula">
        Go to your [User Profile](https://nebulaclient.net/profile) and click **Download** next to your username. Read the popup and click **Confirm Download**.
    </Step>

    <Step title="Install the mod loader">
        We recommend [Prism Launcher](https://prismlauncher.org) for installing and managing game instances, versions, and mods.

        If it's your first time using the launcher:

        - Click **Add Instance** in the top left corner.
        - Select Minecraft version **26.2**.
        - Select the **Fabric** mod loader below and pick the version with a star next to it (usually the latest).
        - Click **OK**.

        If you already have an instance, edit it to use these settings. Make sure you select **Fabric**.
    </Step>

    <Step title="Add Nebula to your mods folder">
        Select your instance and click **Edit** on the right. In the window that opens, select the **Mods** tab.

        Drag the **NebulaLoader.jar** file you downloaded earlier into the mods list.
    </Step>

    <Step title="Launch the game">
        Click **Launch**. On the first launch, the game closes and a Nebula Client popup asks you to restart it. This is expected: Nebula automatically installs **Fabric API**, **Fabric Language Kotlin**, and **HM API**.

        Launch the game again. You should see Nebula's custom main menu. Connect to the server and run `/n`, `/nebula`, or `/nebulaclient` to open the in-game menu.
    </Step>
</Steps>

## Updating

The Nebula loader updates automatically when you start the game. If a required update means you need to download the mod again, we announce it on our Discord server.

## Troubleshooting

If the game crashes or Nebula Client doesn't appear in-game, check that you're using the versions listed in the **Requirements** section.

If you're still stuck, open a ticket in the `#🚑⎮support` channel of our [official Discord server](https://nebulaclient.net/discord).

Common errors and crashes:

<AccordionGroup>
    <Accordion title="Stuck on loading, or 'Mod Download Failed' / 'Validation Error'">
        This usually means there's a problem with your connection to our servers. Some ISPs, school and university networks, and parental control filters throttle or block the download. Regional restrictions can also block it.

        Install [Cloudflare WARP](https://one.one.one.one/), turn it on, and launch the game again. You can also use another VPN.

        If a previous download stopped partway through, the loader needs to replace the incomplete file. Relaunch the game to retry the download.
    </Accordion>

    <Accordion title="'Unsupported Launcher' popup">
        Use [Prism Launcher](https://prismlauncher.org) or MultiMC. The Modrinth App, CurseForge, and Lunar Client can't load Nebula.

        Create a Fabric instance in Prism and place **NebulaLoader.jar** in that instance's mods folder.
    </Accordion>

    <Accordion title="Nebula doesn't load, or the main menu looks normal">
        Check the following in order:

        - Open **Edit -> Version** and check that Fabric is installed. Without Fabric, the game launches but doesn't load Nebula.
        - If this was the first launch, start the game again. Nebula closes the game while it downloads Fabric API, Fabric Language Kotlin, and HM API.
        - Check that the loader's filename ends in `.jar`. Some browsers save it as `.zip` or `.jar.txt`.
        - Make sure the loader is in the mods folder for the instance you're launching, rather than `%appdata%\.minecraft`.
    </Accordion>

    <Accordion title="The game crashes on startup">
        Temporarily remove the other mods and launch the game with only the Nebula loader. If that fixes the crash, add the mods back a few at a time to find which one causes it. **OneConfig** and **Taunahi** are known to be incompatible.

        Check that the mods folder contains only one copy of the Nebula loader. Remove any old or duplicate copies.

        If the game still crashes with only Nebula installed, check your Java version.
    </Accordion>

    <Accordion title="'Incompatible Minecraft Version' or 'Incompatible FabricLoader Version' popup">
        The popup shows the required version and the installed version. Edit your instance to use the required version. Nebula supports one Minecraft version at a time, so newer releases won't work until we add support for them.

        If you typed the version by hand when creating the instance, double-check it.
    </Accordion>

    <Accordion title="Windows or macOS blocks the loader">
        Nebula isn't signed, so Windows Defender, Smart App Control, third-party antivirus software, and macOS Gatekeeper may quarantine it without notifying you.

        Add your instance folder to your security software's exclusions, then download the loader again. Adding an exclusion doesn't restore a file that's already been quarantined.
    </Accordion>

    <Accordion title="Black screen, rendering glitches, or graphics crash">
        On a Mac, update to macOS Tahoe. Sonoma and Sequoia cause black screens and rendering crashes.

        On Windows, update your GPU drivers. If the crash message mentions LWJGL or GLFW, try a different LWJGL version in **Edit -> Settings -> Miscellaneous**.
    </Accordion>

    <Accordion title="Account Information Error: Unable to retrieve account information. Please make sure you are logged in with a valid account and try again.">
        Nebula couldn't read your Minecraft account information. Check that the instance is running in online mode and that you've selected the correct account in Prism before clicking **Launch**.
        The account must own Minecraft. Demo and cracked accounts won't work.

        Too many failed launches in a row will trigger a rate limit. Wait about 15 minutes before trying again.
    </Accordion>

    <Accordion title="Invalid HWID. Please reset it in your account settings if you have a new device.">
        Your license is tied to one computer, and its hardware ID has changed. Switching PCs, changing hardware, reinstalling Windows, or starting another operating system in a dual-boot setup can trigger this error.

        You can reset your HWID for free in your [profile settings](https://nebulaclient.net/profile/settings/account) **once every 3 days**.

        Some customizations, especially custom PowerShell prompt themes, change how your computer is identified and can cause this error to recur on the same PC. If the error returns after a reset, mention that in your support ticket.

        You can use several Minecraft accounts on the same computer. Your license is tied to the hardware, so you don't need to link those accounts.
    </Accordion>

    <Accordion title="Nebula Client Error: Your session has expired, please redownload the loader from the profile page.">
        The session stored in your loader JAR has expired. This usually happens after you haven't played for a while.

        Download a new loader JAR from your [profile page](https://nebulaclient.net/profile) and replace the old one in your mods folder.

        If you keep downloading the same expired file, your browser is using a cached copy. Download it again in a private window.
    </Accordion>

    <Accordion title="Low FPS, freezing, or crashes during a macro">
        Check how much RAM is allocated to the instance in **Edit -> Settings -> Memory**. Allocating less than 2 GB causes FPS to drop over time and eventually leads to crashes. A typical allocation is 4–6 GB. Don't allocate more RAM than you have available.
    </Accordion>
</AccordionGroup>
